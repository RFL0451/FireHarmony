A hot spot that recurs at nearly the same place on several days in a row is often an industrial flare or volcano, not a fire. Hidden points are also excluded from the CSV export.

Matching rule Two detections count as the same fire when they are closer than the distance limit and their times differ by less than the time limit. Move the sliders to see how sensitive the overlap is.

Data loaded from FIRMS API How much data the last load pulled from the NASA FIRMS API. The server caches data in 5-day blocks, so shrinking the time range (for example from 30 days to a week) is served from cache and makes no new API calls.

About this data and method

When the local API proxy is running, the dashboard shows live NASA FIRMS detections; otherwise it falls back to synthetic demo data modelled on FIRMS fields. Harmonization matches each MODIS detection to the nearest unused VIIRS detection inside the distance and time limits, then merges the pair into one record. Anomalous days are those where unique harmonized detections sit at least 2 standard deviations above the period average
